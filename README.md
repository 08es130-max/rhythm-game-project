# Rhythm Game Project

PCブラウザ向けの9レーン・リズムゲーム試作プロジェクトです。

## 方針

- ゲーム本体には市販曲・公式ボイス・公式画像を同梱しません。
- 楽曲は各ユーザーがローカルファイルから読み込みます。
- 譜面はJSONで管理し、曲とは分離します。
- 効果音はWeb Audio APIで生成するため、音声素材は不要です。
- 将来的にボイス差し替え、動画からの譜面抽出、ロングノーツ、スイング、PWA化を追加予定です。

## 現在の試作版

`index.html` をブラウザで開き、音源ファイルと譜面JSONを読み込んでプレイします。

キーボード操作（左から9レーン）:

`A S D F Space J K L ;`

画面上の判定サークルをクリックしてもプレイできます。

## 譜面JSON例

```json
{
  "title": "Sample",
  "offsetMs": 0,
  "notes": [
    { "timeMs": 1000, "lane": 4 },
    { "timeMs": 1500, "lane": 3 },
    { "timeMs": 2000, "lane": 5 }
  ]
}
```

- `timeMs`: 曲の先頭から判定タイミングまでのミリ秒
- `lane`: 0〜8（左から右）
- `offsetMs`: 音源差・端末差の補正値
