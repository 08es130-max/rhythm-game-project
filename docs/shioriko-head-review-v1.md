# 頭部レビュー v1 — 顔・頭部・短い髪

状態：**品質確認待ちの頭部プロトタイプ**。全身完成品ではありません。
人体や髪をカプセル・円錐で組み立てた従来モデルとは別の、新しいGLBです。
ただし、初期トポロジーは制御点を指定したBlender Pythonで構築したものであり、熟練者による手彫りの完成モデル、あるいはユーザー承認済みの造形とは扱いません。

## 成果物

- 編集用：`assets/models/shioriko/source/shioriko-head-v1.blend`
- 表示用：`assets/models/shioriko/prototypes/shioriko-head-v1.glb`
- 再構築スクリプト：`tools/blender/shioriko_head_study.py`
- 基準画像：`assets/home-characters/shioriko/new/normal.png`（元画像は変更せず、.blendに参考画像としてパック）

顔、目、虹彩、まぶた、まつ毛、眉、口、耳、前髪、横髪、後ろ髪、編み込みを分離。
顔は断面の連続曲面、髪は幅・厚み・流れを持つ個別のメッシュで作成しています。
髪には編集用のSubdivisionモディファイアが残り、各毛束の元制御点をカスタムプロパティに保存しています。
GLB出力時だけ髪をまとめ、描画呼び出しを抑えています。編集用.blendの髪束は結合していません。

Blender 4.5.0で実際にシーン生成・保存・4方向レンダリング・GLB出力を実施しました。

## 編集と再出力

Blenderで`.blend`を開き、`01_FACE` / `02_EYES` / `03_HAIR`の対象を選択してEdit ModeやSculpt Modeで調整してください。
`00_REFERENCE`には承認済みホーム立ち絵、`90_STUDIO`には正面・斜め・横・背面カメラと照明があります。
前髪と髪束の幅・分け目・毛先、顔の輪郭と目の大きさの類似度を優先して確認します。

再構築する場合：

```sh
blender --background --python-exit-code 1 --python tools/blender/shioriko_head_study.py -- --out work/head-review-regenerated --render
```

**再構築は手作業で編集したシーンを取り込みません。手修正した.blendに上書きせず、必ず別の出力フォルダーを指定してください。**
手修正後は、参考画像・スタジオを除く頭部メッシュとHeadRigを選択し、選択物のみGLBで書き出します。
形状を変更した後は4方向の確認とglTF Validatorを再実行してください。
本番全身用の`shioriko_export.py`は全身・衣装・表情の不足を正しくエラーにするため、この頭部だけの提出には使用しません。
